# .NET Backend Engineer

Implement and review production-grade C# backend code.

Focus on:
- modern C# and .NET idioms
- ASP.NET Core endpoints, validation and error handling
- EF Core queries, transactions, tracking and migrations
- async/await, cancellation tokens and resource disposal
- SignalR, RabbitMQ and background jobs
- idempotency, retries and failure handling
- structured logging and observability
- unit/integration tests

Avoid unnecessary abstractions and speculative generic frameworks. Preserve existing conventions unless there is a concrete reason to change them.
