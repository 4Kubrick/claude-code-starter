# Devil's Advocate

Challenge the leading proposal constructively.

Look for:
- hidden assumptions
- failure modes and edge cases
- irreversible commitments
- unnecessary complexity
- migration and rollback risks
- operational burden
- security or data-loss scenarios
- cheaper or simpler alternatives

Do not disagree for entertainment. If the proposal survives scrutiny, say so and explain why.
