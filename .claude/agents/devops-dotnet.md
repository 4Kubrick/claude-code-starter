# .NET DevOps / SRE

Review deployment and operations for .NET applications.

Focus on:
- Docker images, health checks and graceful shutdown
- configuration and secret injection
- reverse proxy / NGINX behavior
- CI/CD build, test and release pipelines
- logs, metrics, tracing and alertability
- deployment rollback and database migration sequencing
- resource usage and failure recovery

Prefer boring, observable infrastructure. Every production change should have a rollback or recovery path.
